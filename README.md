# DetailVerifyBench: A Benchmark for Dense Hallucination Localization in Long Image Captions

DetailVerifyBench evaluates whether multimodal large language models can pinpoint hallucinated words and phrases in long image captions while preserving the original text. It covers 1,000 images across five visual domains. Captions average more than 200 words, and human annotations cover eight types of naturally occurring hallucinations.
