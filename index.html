DetailVerifyBench:A Benchmark for Dense Hallucination Localization in Long Image Captions

Anonymous Authors

Dataset Leaderboard

Abstract

Long image captions describe objects, attributes, spatial relations, and visual text in detail, but even a small number of hallucinated spans can undermine their reliability. Can multimodal large language models (MLLMs) accurately pinpoint these hallucinated details in long captions? In order to evaluate this ability, we introduce DetailVerifyBench, a benchmark that requires multimodal large language models to identify the specific words or phrases that do not match the image. It contains 1,000 images from graphical user interfaces, natural scenes, charts, movie frames, and posters, paired with captions averaging over 200 words and human annotations of advanced multimodal large language model hallucinations. Captions from different domains can contain several subtle errors, such as misread interface text or chart values, incorrect object attributes, and wrong spatial relations. Finding these errors requires models to check a wide range of visual details carefully. We evaluate a range of open-source and proprietary advanced MLLMs. The evaluation results show that even advanced MLLMs struggle to locate subtle hallucinations in long captions. We also provide a simple reinforcement-learning baseline using Qwen3-VL-4B, with training data synthesized through multiple rounds of adversarial hallucination injection.

Evaluation Metrics and Valid-Output Coverage

Precision: how many marked words are actually errors.

Recall: how many true error words are found.

FPR: false alarms among valid outputs for error-free captions.

ZOR: valid nonempty predictions that overlap no reference error word.

Scoring units: real-test results use words; synthetic and domain results use tokens.

Invalid outputs count as empty predictions in Word scoring. FPR and ZOR use the valid-output subsets described in the paper.
